## Summary
The page does not prevent submission of an empty form, allowing a payment request to be sent. This is a critical security vulnerability.

## Steps to reproduce
1. Navigate to the Bill Pay page
2. Fill in none of the required fields
3. Submit the form

## Expected
The page should prevent submission of an empty form and display error messages for each missing field.

## Actual
A payment request was sent with an empty form.

## Evidence (checked: each quote occurs in the failure)
- `Payee Name: Payee name is required.`
- `Address: Address is required.`
- `City: City is required.`
- `State: State is required.`
- `Zip Code: Zip Code is required.`
- `Phone #: Phone number is required.`
- `Account #: Account number is required.`
- `Verify Account #: Account number is required.`
- `Amount: $ The amount cannot be empty.`

## Suspected cause
The page's validation logic is not correctly implemented.

## Next action
The development team should review and fix the page's validation logic to prevent empty form submissions.
